Frequently asked questions

Do I need a Google API key to use Veraph?

For the Knowledge Graph Explorer, yes — you'll need a free Google Cloud API key. We walk you through getting one in under 5 minutes. The Entity Explorer uses public Wikidata and DBpedia data with no key required.

Is my API key stored securely?

Yes. API keys are stored as encrypted environment variables and never exposed publicly. We use industry-standard security practices to keep your credentials safe.

Can I cancel anytime?

Absolutely. There are no long-term contracts. You can cancel your subscription at any time and you'll retain access until the end of your billing period.

What is a knowledge graph and why does it matter for personal brands?

Google's Knowledge Graph is a database of entities — people, brands, places and concepts — that Google uses to understand the world. If your personal brand is recognised as an entity, you're far more likely to appear in knowledge panels, entity-based queries and AI-generated search summaries.
